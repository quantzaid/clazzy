# Clazzy — Student Attendance Management App

Clazzy is an Android application designed to help students manage and track their class attendance conveniently.

## Features

* Student-focused attendance management.
* Simple and convenient interface.
* Designed to help students keep track of their attendance.

## Installation

1. Download the APK to your Android device.
2. Open the downloaded file.
3. Follow Android's installation instructions.

Only install APK files from sources you trust.
